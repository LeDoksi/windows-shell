# Прототип на WinUI 3 (WSH-E13)

Тот же док, что в версии на Tauri, но на родной технологии Windows 11 (WinUI 3, C#).
Нужен, чтобы сравнить обе версии на одном ПК и решить, переезжаем ли (vision-2026-10, п. 4).

Что есть:

- **Док** на реальных окнах: кнопка Пуска, закреплённые и запущенные программы, точки
  (активное шире), увеличение волной с пружиной, подпись через 400 мс, список окон с живыми
  миниатюрами через 500 мс у программ с 2+ окнами. Клик, Shift+клик, Ctrl+Shift+клик,
  средний клик и двойной клик как в разделе 1.3 описания поведения.
- **Меню** правого клика (1.4): своё окно с настоящим стеклом, подменю «Добавить в категорию»
  через 300 мс, стрелки, Enter, Esc, повторный клик закрывает, правый клик по другой иконке
  перескакивает.
- **Окошко звука** (2.3): устройство вывода, громкость, приложения, микрофон. Колесо над
  иконкой ±2 %, средний клик выключает звук, правый клик — меню.

Чего нет (это следующие этапы): автоскрытие, перетаскивание, верхняя панель, свой Пуск
(кнопка открывает родной), трей, несколько мониторов (док только на основном).

Закреплённое и категории при первом запуске берутся из конфига версии на Tauri
(`%APPDATA%\com.ledoksi.windowsshell\config.json`, только чтение). Дальше прототип пишет в
свой файл `%APPDATA%\WindowsShellNative\prototype.json`. Панель задач Windows не трогает.
Выход: правый клик по кнопке Пуска → «Выйти из прототипа».

## Сборка

Нужен .NET 8 SDK. Готовая сборка лежит в артефакте CI `windows-shell-native-<коммит>`.

```
dotnet publish native/Shell/Shell.csproj -c Release -r win-x64 -o native/publish
native\publish\WindowsShellNative.exe
```

В Linux-контейнере C# проверяется так (шаги, которым нужен Windows, падают, это нормально;
важно, что нет `error CS`):

```
dotnet build native/Shell/Shell.csproj -p:WindowsAppSDKSelfContained=false 2>&1 | grep "error CS"
```

## Как устроено

- `Dock/Dock.cs` — два окна: снизу таблетка со стеклом (`AlwaysActiveAcrylic`: Acrylic не гаснет,
  хотя окно никогда не активно), сверху прозрачная полоса с иконками. Каждый кадр двигаются только
  визуалы (`Translation`/`Scale`), без раскладки. Пока курсор не над доком, полоса ловит мышь
  только на таблетке (`SetWindowRgn`).
- `Ui/Popup.cs` — всплывающие окошки: одно открыто, повторный клик закрывает, клик мимо закрывает
  и срабатывает, фокус возвращается прежнему окну.
- `Apps/` — порт трекера окон, запуска и иконок из `src-tauri/src/apps.rs`, `launch.rs`, `icons.rs`.
- `Audio/` — Core Audio напрямую (как `audio.rs`), без сторонних библиотек.
