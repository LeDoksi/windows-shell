# WSH-E26 «Остров · Волна 4» — план

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (Георгий выбрал «Сам подряд» = native, 2026-11-07). Шаги — чекбоксы.

**Goal:** последняя волна острова. Собственный центр уведомлений в острове заменяет баннеры Windows без молчаливых потерь (вариант А, И3, П18, П21, П25); OCR — текст с экрана (Ctrl+PrtSc и кнопка в «Снимках») и из сохранённых снимков, проверка и правка в острове, копирование после подтверждения (И6); преобразования буфера в Win+V с просмотром «было → стало» (раскладка, регистр, переносы); Bluetooth внутри виджета сети — свои устройства, подключение наушников по кнопке, сопряжение новых с PIN прямо в острове (И4).

**Architecture:** остров — путь b1 волн 1–3 без изменений. Уведомления: опрос `UserNotificationListener` раз в секунду (события без пакета недоступны — итог пробы И3), новые id → `Notice` в `NoticeStore` (чистая логика: группы, пачки, «прочитано», 3 дня, файл `notices.json`), событие острова — пилюля (`EventKind.Notice`, маршрут как у снимка). Оригиналы в центре Windows не трогаем (П25). Баннеры Windows оболочка сама не выключает: это настройка Windows, её включает Георгий («Не беспокоить» Windows, кнопка прямо в острове). Пока «Не беспокоить» Windows выключено, остров уведомления только собирает (без пилюль) — так нет дублей; включено — остров показывает пилюли. Свои тосты оболочки (ошибки записи, «канбан подключён», буфер) при работающем острове идут событиями острова, а не тостами. Сторож при «Не беспокоить» показывает «Оболочка не запускается» обычным окном сообщения, а не только тостом (тост спрятался бы). OCR — `Windows.Media.Ocr` по картинке, увеличенной для мелкого текста; результат живёт в виджете «Снимки». Преобразования — чистый `Clips/TextFix.cs`. Bluetooth — узлы PnP (как у заряда, быстро), подключение аудио — `IOCTL_KS_PROPERTY` `KSPROPSETID_BtAudio` (ONESHOT_RECONNECT/DISCONNECT) на KS-фильтрах того же контейнера, сопряжение — `DeviceInformationCustomPairing`.

**Tech Stack:** C# / .NET 8, WinUI 3 (код без XAML), xUnit, WinRT (`Windows.UI.Notifications.Management`, `Windows.Media.Ocr`, `Windows.Devices.Bluetooth`, `Windows.Devices.Enumeration`, `Windows.Devices.Radios`), cfgmgr32.

**Spec:** концепция `docs/superpowers/specs/2026-11-07-dynamic-island-concept.md` (раздел 2 «Уведомления», «Буфер», «OCR», «Bluetooth»; решения 2026-11-07 — вариант А; П7, П18, П20, П21, П25; И3 и «Итог пробы» И3, И4, И6), карта `2026-11-07-dynamic-island-roadmap.md`, эскизы https://claude.ai/artifact/K4bXtAcoReEqeGQySkQ8zu (Events, NotifCenter, NetBT, ShotsOcr, BinClips).

## Global Constraints

- Всё из волн 1–3 в силе (кромка, наведение, motion, фокус, клики сквозь, fullscreen, один раскрытый остров, WDA_EXCLUDEFROMCAPTURE, пилюля записи, закреплённый монитор).
- Не вернуть отклонённое: выключатели уведомлений по приложениям, глобальный хоткей острова, события канбана.
- Молчаливая потеря недопустима: всё, что Windows положила в свой центр, попадает в наш центр (в том числе пришедшее, пока оболочка была выключена или перезапускалась — подхват при старте, без пилюль). Оригиналы не удаляем (П25), Win+N остаётся запасным.
- Вариант А: клик по уведомлению открывает приложение-источник (окно уже открыто — выводим его вперёд, иначе запуск по AUMID). Кнопок и ответа нет.
- П7: пачка от одного приложения, пока пилюля видна, — одна пилюля с последним сообщением и «ещё N»; в центре остаются все. Наведение держит пилюлю.
- В игре на весь экран — пилюля на свободном другом экране, иначе тихо в центр (В2, П6). После выхода из игры ничего не «высыпается».
- «Не беспокоить» острова — своя настройка, не режим Windows: тихо копит, без пилюль и звука, без залпа после выключения. Точка на кромке и в ленте (П20, П21) — есть непрочитанное.
- Изменения настроек Windows делает только Георгий (кнопка открывает нужную страницу Параметров). Оболочка их не меняет.
- П18: группы по приложениям, новые сверху; открыли центр — всё прочитано; «Очистить» у группы и «Очистить всё»; хранение 3 дня с получения.
- Текст чужих уведомлений не пишем в журнал (только приложение и длина) — журнал Георгий пересылает.
- OCR: результат сначала виден и правится в острове, в буфер — только по «Копировать». Язык — русский, если он есть в Windows, иначе язык профиля; переключатель языков, если их несколько. Нет распознавания — честное сообщение и кнопка «Языки Windows».
- Буфер (Win+V) остаётся у места ввода. Преобразование — только содержимое буфера, применяется после просмотра «было → стало» («Вставить» или «Только скопировать»); оригинал остаётся в истории.
- Bluetooth: сопряжённые устройства видны сразу (узлы PnP, без 30-секундного WinRT-списка); заряд BT-устройств остаётся в виджете заряда. Подключить/отключить по кнопке — только для аудио; не вышло — понятный текст и «Параметры Bluetooth». Удалить устройство — с подтверждением.
- Тексты по-русски, длинные подписи — многоточие. Новых окон нет: всё в теле острова (Win+V — в своём окошке у курсора, как было).

## Review Focus

1. Уведомление пришло, пока оболочка перезапускалась, — после старта оно в центре (непрочитанное), пилюли нет (`NoticeStoreTests.ImportIsQuiet`).
2. «Не беспокоить» Windows выключено — пилюль нет (баннер Windows уже показан), всё в центре; включено — пилюля. Своё «Не беспокоить» острова — никогда пилюль (`NoticeRuleTests`).
3. Пачка: 5 сообщений Telegram за 3 с — одна пилюля «… · ещё 4», в центре 5 (`NoticeStoreTests.BurstOnePill`).
4. Ctrl+PrtSc — выбор области → текст в острове на экране активного окна; Esc в выборе — ничего не происходит; PrtSc без Ctrl работает как раньше (`--prtsc-test` 12/12 не ломается).
5. «ghbdtn? rfr ltkf&» → «привет, как дела?»; «руддщ» → «hello»; в смешанном тексте направление по большинству (`TextFixTests`).
6. Сопряжение с PIN: окно не активируется само, ввод PIN в острове, «Отмена» отменяет сопряжение, не вешает оболочку (deferral завершается всегда).

## Состояния (раздел 10 концепции)

| Состояние | Что делает волна 4 |
| --- | --- |
| Событие вне игры | пилюля уведомления — на экране активного окна |
| Игра на весь экран | на свободном другом экране, иначе тихо в центр |
| Нет интернета | не влияет (уведомления локальные); Bluetooth/OCR работают без сети |
| Монитор отключили | тело убирается (волна 1), пилюля не теряется — уведомление в центре |
| Сон/пробуждение | опрос продолжается; пришедшее во сне — в центре без залпа пилюль (новые за раз > 3 — одна пилюля «N новых») |
| Перезапуск Проводника / падение оболочки | подхват при старте из центра Windows (тихо) |
| Клавиатура и диктор | у строк уведомлений, чипов преобразований, PIN-поля — имена для диктора; Tab/Enter/Esc |
| Длинные подписи | заголовок/текст уведомления — многоточие, 2 строки; имена BT-устройств — многоточие |
