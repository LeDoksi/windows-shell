# Dynamic Island — дорожная карта разработки

2026-11-07. Концепция утверждена Георгием («все подтверждаю», 2026-11-07):
`docs/superpowers/specs/2026-11-07-dynamic-island-concept.md`.

Остров — несколько независимых подсистем, поэтому план разбит на эпики. Подробный
план по задачам пишется **в начале треда каждого эпика**, а не сейчас: результаты
проб (шаг 0) меняют устройство ядра, и план волны 1, написанный до них, устареет.
Готов подробный план только шага 0: `2026-11-07-dynamic-island-step0-spikes.md`.

## Правила для всех эпиков

- Один эпик = один тред = одна ветка = один PR (как E16–E21). Тред начинается
  с `handoff.md`, этой карты, концепции и памяти; в конце обновляет handoff и память.
- Перед кодом эпика его задачи заводятся в канбане Георгия (проект «Windows Shell»,
  префикс WSH), эпики — WSH-E22…E26.
- Проверка на mephPC: клон всегда на `main`; ветку собираем в отдельной папке
  (worktree), скрипт обновления собирает только `main`. После слияния RC подтягивает
  `main` в клон.
- Миграция только дублированием: виджет появляется в острове, док не трогаем, пока
  Георгий не нажмёт «Проверил — убрать из дока» на странице «Перенос» (П24).
- Компиляцию проверяем в облаке (`dotnet build native/check`), чистую логику —
  `dotnet test native/tests/Island.Tests`, поведение — самопроверками `--…-test`
  на mephPC и руками Георгия.
- Не вернуть отклонённое (раздел 3 концепции).

## Что каждая волна обязана покрыть (из раздела 10 концепции)

Каждый пункт — строка в подробном плане волны, где он впервые нужен (обычно E23):
события вне игры — на экране активного окна; индикатор записи — на записываемом
экране; нет интернета; монитор отключили при раскрытом острове; сон/пробуждение;
смена DPI во время анимации; перезапуск Проводника; восстановление после падения;
клавиатура и диктор внутри острова; reduced motion из «Эффектов анимации» Windows;
длинные русские подписи.
