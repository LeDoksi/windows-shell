# WSH-E25 «Остров · Волна 3» — план

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (Георгий выбрал «Сам подряд» = native, 2026-11-07). Шаги — чекбоксы.

**Goal:** в острове появляются «Монитор ПК» (полный виджет + закрепление компактной строкой на выбранном экране, П8) и канбан («Нужно от тебя» с галочкой, быстрая задача с типом и новым эпиком, П10–П12, П22); FPS-оверлей сам появляется в играх Георгия (новое распознавание игр И8, FPS + 1% low, честное «нет данных» вместо пустоты, П16); полное окно канбана переделано в стиле острова и «как на сайте» (колонки и подписи сайта, группы эпиков, архив с поиском и «Вернуть», П13).

**Architecture:** остров — путь b1 из волн 1–2 без изменений. Закреплённый монитор живёт в том же механизме, что постоянная пилюля записи (`BodyMode.Badge`): у тела теперь не одна постоянная пилюля, а слоты `rec` и `pin`, собранные в одну строку; тело возвращается в неё после ленты/виджета и не сворачивается, когда открывают остров на другом экране. Открытие полного виджета из строки — без активации окна (П8). Чистая логика (место закрепления, сбор кадров, правило «игра», доска канбана: колонки, группы эпиков, архив, поиск) — в тестируемых классах. Канбан-логика доски переезжает в `Kanban/Board.cs` (только System.*), её тесты идут в Island.Tests (файлы подключаются ссылкой, как Core).

**Tech Stack:** C# / .NET 8, WinUI 3 (код без XAML), xUnit, PresentMon 2.3.1 (уже в сборке), Supabase REST.

**Spec:** концепция `docs/superpowers/specs/2026-11-07-dynamic-island-concept.md` (раздел 2 «Канбан», «Монитор ПК», «FPS»; П8, П10–П13, П16, П20, П22, П24; И8 и «Итог пробы» И8), карта `2026-11-07-dynamic-island-roadmap.md`, эскизы https://claude.ai/artifact/K4bXtAcoReEqeGQySkQ8zu (Pinned, KanbanIsland, KanbanWindow), исходники сайта `LeDoksi/kanban` (`web/src/columns.ts`, `done.ts`, `archive.ts`, `epics.ts`, `CreateModal.tsx`, `Board.tsx`).

## Global Constraints

- Всё из волн 1–2 в силе (кромка, наведение, motion, фокус, клики сквозь, fullscreen, один раскрытый остров, WDA_EXCLUDEFROMCAPTURE, пилюля записи).
- Не вернуть отклонённое: закрепление любого виджета, кроме монитора ПК; отдельное окно монитора ПК в целевой модели; счётчик «В работе» у канбана; события канбана; глобальный хоткей острова.
- Миграция дублированием (П24): окно «Монитор ПК» и значок канбана в доке остаются, пока Георгий сам не нажмёт «Проверил — убрать…» на странице «Перенос». Для монитора «старое» — это окно (в доке его нет): кнопка «Проверил — убрать окно», после неё раздел окна в настройках прячется и окно закрывается; «Вернуть окно» — откат.
- П8: закреплённый монитор не забирает фокус ни при наведении, ни при клике, раскрывающем полный виджет. Прежнего экрана нет — закрепление «спит» и нигде не появляется; в виджете на другом экране: «Закреплён за экраном N — сейчас не подключён» и «Открепить». После перезапуска оболочки — на том же экране (по имени монитора). На том же экране другой виджет временно заменяет строку, после закрытия строка возвращается. Открытие острова на другом экране строку не трогает.
- Строка закрепления (В4-А): компактно у верхнего края, выбранные показатели (по умолчанию «ЦП % °C · ГП % °C · ОЗУ · ВП»), значок-скрепка; настраивается на странице «Монитор ПК».
- FPS-оверлей (П16): по умолчанию FPS + 1% low; время кадра и маленький график времени кадра — по желанию. Пока кадров мало — «—», не ноль. Кадров нет совсем (эксклюзив и т. п.) — «FPS —» и в виджете «нет данных», а не пустое место. Оверлей по умолчанию не попадает в снимки и запись (WDA_EXCLUDEFROMCAPTURE; выключатель «Показывать в записи»). В оверлее только кадровые показатели по умолчанию (остальные датчики остаются доступными, как сейчас).
- Распознавание игр (И8, «никаких заплаток под игры»): ручная отметка → «никогда» → лаунчер/список Windows → **окно на переднем плане в настоящем fullscreen, которое рисует кадры** (PresentMon смотрит только этот процесс, 4 с) → не игра. Постоянной слежки за всеми процессами нет. Решение по процессу запоминается до его выхода. Каждое решение — строка в логе.
- Канбан (П10, сайт `columns.ts`): статусы и порядок **Hold · Backlog · В работе · Нужно от тебя · Готово**; типы: задача — без метки, `bug` — «баг» (красная), `chore` — «долг» (серая). Данные не меняются. Счётчик у значка (лента и док) — неархивные `waiting` в неархивных проектах; при нуле скрыт.
- П11: круглая галочка ≥ 32×32 на карточке (в острове 36, в окне 30 + отступы до 34), «Отменить» ~6 с (вернуть статус, место и `closed_at` как `undoPatch` сайта).
- П12: «+ Новый эпик» последним пунктом выбора эпика; эпик и задача создаются одним «Создать»: эпик не создался → задачи нет, черновик цел, ошибка видна. Эпик: `id = {prefix}-E{seq}`, `seq = rpc next_seq(p_kind='epic')`, `position = seq*100`, `status = active` (как `CreateModal.tsx`).
- Архив (сайт `Board.tsx`, `ArchiveList.tsx`): «Готово» в колонке — последние 5 закрытых (`DONE_SHOWN`); архив = архивные + «Готово», не поместившиеся в колонку, свежие сверху; поиск без регистра, ё = е, по названию и id; «Вернуть» только у архивных → `status = doing, archived_at = null`; «В архив» — у закрытых.
- Нет интернета / нет входа: канбан явно пишет «Нет связи с канбаном…» / «Войди через Google», без пустых списков.
- Тексты по-русски, длинные подписи — многоточие.

## Review Focus

1. Игра на весь экран на экране 1, монитор закреплён на экране 2, Георгий кликает строку → полный виджет на экране 2, игра остаётся на переднем плане и не сворачивается (самопроверка: `GetForegroundWindow()` до и после клика по строке один и тот же; тест `PinTests` — место закрепления).
2. Отключили монитор с закреплением, потом подключили — строка исчезает без следа и возвращается на тот же экран, нигде больше не всплывает (`PinTests.SleepsWhenScreenGone`, `ComesBack`).
3. Процесс на весь экран, не игра (видео в браузере на весь экран, презентация) — оверлей не появляется: браузеры/плееры в «никогда»; процесс без кадров 4 с — «не игра» (`GameProbeTests.NoFramesNotGame`, `NeverListSkipsProbe`).
4. Эксклюзивная игра, PresentMon не даёт ни одной строки для pid — через 4 с переход в «широкий» режим (все процессы, строки фильтруются по pid игры), в логе — кто рисует; всё ещё пусто — «нет данных», а не мигающий ноль (`FrameStatsTests.DisplayedNaFallsBackToPresented`, ручная проверка CS2).
5. «Создать» с новым эпиком без сети — ни эпика, ни задачи, черновик в поле, ошибка видна (`KanbanService.CreateWithEpic` порядок вызовов; ручная проверка с выключенным Wi-Fi).
