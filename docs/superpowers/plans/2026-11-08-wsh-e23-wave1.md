# WSH-E23 «Остров · Волна 1» — план

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (Георгий выбрал «Сам подряд» = native, 2026-11-07). Шаги — чекбоксы.

**Goal:** настоящий остров на каждом мониторе рядом с доком: кромка, лента-приборная панель, тело с пружинами и магнитом, клики сквозь, fullscreen по мониторам; в острове — звук, медиа (вариант B), сеть (Wi-Fi с паролем), заряд, раскладка; события «раскладка» и «низкий заряд»; страница «Остров» с «Переносом».

**Architecture:** путь b1 из E22: одно неподвижное прозрачное окно WinUI на монитор (`ShellWindow`, layered), форма — `Path` по `IslandShape.Outline`, клики — `SetWindowRgn` по контуру, в покое окно сквозное (`WS_EX_TRANSPARENT`). Всё, что можно проверить без Windows, — в `Island/Core` с тестами. Виджеты — классы-«виды» внутри тела, каждому телу свои экземпляры (не переносим элементы между окнами, см. winui-tree-gotchas). Док не трогаем, кроме скрытия значков, которые Георгий сам убрал на странице «Перенос».

**Tech Stack:** C# / .NET 8, WinUI 3 (код без XAML), xUnit для Core.

**Spec:** `docs/superpowers/specs/2026-11-07-dynamic-island-concept.md` (разделы 2, 4, 5 И2/И5/И7, 10), карта `docs/superpowers/plans/2026-11-07-dynamic-island-roadmap.md`, эскизы https://claude.ai/artifact/K4bXtAcoReEqeGQySkQ8zu (Main, Ribbon, SoundCharge, Media, Network, Events, Settings).

## Global Constraints

- Остров на каждом мониторе, по центру верхнего края; кромка 3 логических px, тёмная с еле заметным светлым контуром, прозрачна для кликов (П4); в fullscreen кромки нет.
- Наведение: упор в верхний край в зоне острова ~150 мс; при зажатой кнопке мыши не реагирует; ушёл с ленты — прячется через ~0,4 с (П1). В fullscreen наведение выключено. Глобального хоткея нет.
- Виджет закрывается кликом снаружи или Escape; уход мыши не закрывает. Раскрыт один остров (открытие на другом экране сворачивает прежний).
- Motion: лента ≈200 мс, виджет ≈300, смена ≈250, ничего > 400 мс; новый клик перенаправляет движение; контент проявляется на последней трети; магнит только под телом (~150 px), в покое слабее, без курсора — ноль движения; пилюля ≈220 мс / уход ≈160; reduced motion — без пружин (настройка Windows «Эффекты анимации»).
- Фокус (П5): наведение и лента фокус не берут; клик в виджет берёт, при закрытии фокус возвращается прежнему окну.
- В покое ноль работы, кроме опроса курсора 16 мс в фоне (как Bars); CPU в покое не хуже ≈0,02 %.
- Остров не попадает в снимки и запись (WDA_EXCLUDEFROMCAPTURE, П9).
- Лента: медиа на постоянном месте, без сессии приглушено; значки не сдвигаются. Состав и порядок общие для экранов и настраиваются; значок и события виджета включаются отдельно.
- События не переключают открытый виджет. Раскладка: только при фактической смене, ≈1 с, «EN»/«RU», на экране активного окна, в fullscreen подавляется, на другой экран не уходит. Низкий заряд показывается и поверх игры; звук в наушники в игре сохраняется; тост Windows о заряде при включённом острове заменяется пилюлей (без дубля).
- Миграция: док не меняется, пока Георгий сам не нажмёт «Проверил — убрать из дока»; «Вернуть в док» всегда есть. Агент эту кнопку не нажимает.
- Wi-Fi (П15): открытые и WPA2/WPA3-Personal с паролем в острове; корпоративные и скрытые — «Открыть в параметрах Windows»; пароль нигде не логируется.
- Медиа (П19, П23): жест с кольца — только перемотка до отпускания; без длительности/перемотки кольцо не интерактивно; выбор плеера — только при нескольких сессиях. Обложки — универсальная правка (И7), без точечного кода под Яндекс.
- Тексты по-русски; длинные подписи обрезаются многоточием с подсказкой, не ломают ленту.

## Review Focus

1. Окно Explorer по Win / Пуск / поиск на переднем плане при игре — игра не должна «сняться» с монитора, остров не должен мигнуть (тест `ShellUiTests`, `FullscreenWatchTests.ShellUiKeepsGame`).
2. Эксклюзив (состояние 3) и окно на другом мониторе — тот монитор не fullscreen (тест `ExclusiveOwnerTests.OtherMonitorNotFull`).
3. Монитор отключили / поменяли масштаб, пока остров раскрыт — тело пересоздаётся или переставляется, без падения (Task 6, ручная проверка + try/catch).
4. Неверный пароль Wi-Fi — форма остаётся с введённым, профиль удаляется, текст ошибки виден (тест `WifiProfileTests`, Task 9).
5. Медиа без длительности (радио, браузер) — кольцо не интерактивно, клик по центру = пауза (тест `MediaRingTests.NoDurationNotSeekable`).
