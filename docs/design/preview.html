Shell Glass

Живой макет по концепту: наведи на док, чтобы увидеть увеличение; нажми на иконку звука справа в доке, чтобы открыть аудио-виджет; правый клик по плитке открывает меню. Значения ниже — те же токены, что пойдут в tokens.css.

Стекло здесь сделано через CSS backdrop-filter. В приложении blur даёт DWM Acrylic, а тонировка, обводка, блик и тень остаются в CSS. Кнопка «Без blur» показывает, как выглядит фолбэк при выключенных эффектах прозрачности.
