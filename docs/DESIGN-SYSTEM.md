# Дизайн-система «Shell Glass»

Тёмное полупрозрачное стекло поверх обоев, как на [концепте](concept.png). Ощущение: floating, premium, clean, responsive. Живое превью токенов и компонентов — в артефакте (ссылка в PR).

## Принципы

1. **Обои — главный герой.** Интерфейс появляется по необходимости и уходит. Никаких постоянно видимых крупных поверхностей.
2. **Одно стекло, много уровней.** Все поверхности — один материал; иерархию задают плотность тонировки, обводка и тень, а не разные цвета.
3. **Нативность Windows 11.** Шрифт Segoe UI Variable, иконки Fluent, скругления и motion в духе системы, но без копирования macOS или Windows буквально.
4. **Стекло должно выглядеть достойно и без blur.** Если DWM-размытие недоступно (или выключено «Эффекты прозрачности»), остаётся тонировка + обводка + тень, и это не ломает вид.
5. **Доступность**: фокус с клавиатуры видим, контраст текста ≥ 4.5:1 на тонировке, уважение `prefers-reduced-motion` и системного «Эффекты прозрачности».

## Слои стеклянной поверхности

```text
┌ тень (elevation)                 — отрывает от фона
│┌ обводка 1px stroke              — читаемый край на любом фоне
││┌ блик сверху (inset highlight)   — объём
│││┌ тонировка (surface tint)       — плотность, читаемость текста
││││┌ backdrop: DWM Acrylic        — настоящий blur того, что под окном
```

## Токены

Все токены — CSS-переменные с префиксом `--ws-`, лежат в `src/shared/design/tokens.css`. В TS — `tokens.ts` с теми же именами для Rust/JS-логики (например, размеры дока).

### Цвет

| Токен | Значение | Где |
|---|---|---|
| `--ws-surface` | `rgba(16, 32, 46, 0.62)` | Dock, верхняя панель |
| `--ws-surface-strong` | `rgba(12, 26, 38, 0.80)` | Окно категории, flyout, меню |
| `--ws-fill` | `rgba(255,255,255,0.06)` | Плитки, поля ввода |
| `--ws-fill-hover` | `rgba(255,255,255,0.10)` | Hover |
| `--ws-fill-pressed` | `rgba(255,255,255,0.04)` | Pressed |
| `--ws-stroke` | `rgba(255,255,255,0.10)` | Обводка поверхностей и плиток |
| `--ws-stroke-strong` | `rgba(255,255,255,0.18)` | Обводка при hover, разделители дока |
| `--ws-text` | `#EEF4F8` | Основной текст |
| `--ws-text-2` | `rgba(238,244,248,0.66)` | Подписи («Приложение», «Документ · 2.4 МБ») |
| `--ws-text-3` | `rgba(238,244,248,0.44)` | Плейсхолдеры, неактивное |
| `--ws-accent` | `#3D8EF0` | Активная категория, ползунки, индикатор |
| `--ws-accent-fill` | `rgba(61,142,240,0.38)` | Фон выбранной «таблетки» |
| `--ws-focus` | `#8CC4FF` | Кольцо фокуса 2px |
| `--ws-danger` | `#FF7A7A` | Mute, удаление |

### Форма

| Токен | Значение | Где |
|---|---|---|
| `--ws-radius-sm` | 8px | Пункты меню, мелкие кнопки |
| `--ws-radius-md` | 12px | Плитки, кнопки, поле поиска, иконки в доке |
| `--ws-radius-lg` | 16px | Окно категории, flyout, верхняя панель |
| `--ws-radius-xl` | 22px | Dock |
| `--ws-radius-pill` | 999px | Таблетки категорий, тумблеры |

Отступы — сетка 4px: `--ws-space-1..8` = 4, 8, 12, 16, 20, 24, 32, 40.

### Тени

| Токен | Значение |
|---|---|
| `--ws-elev-1` | `0 2px 8px rgba(0,0,0,.18)` — плитки при hover |
| `--ws-elev-2` | `0 8px 24px rgba(0,0,0,.28)` — панель, dock |
| `--ws-elev-3` | `0 18px 48px rgba(0,0,0,.38)` — окно категории, flyout, меню |
| `--ws-highlight` | `inset 0 1px 0 rgba(255,255,255,.08)` |

### Типографика

Шрифт: `"Segoe UI Variable Text", "Segoe UI", system-ui`; для заголовков — `"Segoe UI Variable Display"`.

| Токен | Размер / межстрочный / вес | Где |
|---|---|---|
| `--ws-type-caption` | 11 / 14 / 400 | Подписи плиток, часы |
| `--ws-type-body-sm` | 12 / 16 / 400 | Меню, списки |
| `--ws-type-body` | 13 / 18 / 400 | Основной |
| `--ws-type-label` | 13 / 18 / 600 | Названия плиток, категорий |
| `--ws-type-title` | 16 / 22 / 600 | Заголовок окна категории |
| `--ws-type-section` | 11 / 14 / 600, uppercase, +0.06em | Секции настроек, «ПРИЛОЖЕНИЯ» |

### Motion

| Токен | Значение | Где |
|---|---|---|
| `--ws-dur-fast` | 120ms | Hover, pressed |
| `--ws-dur-base` | 180ms | Появление меню, flyout |
| `--ws-dur-slow` | 260ms | Выезд панели/дока из-за края |
| `--ws-ease-standard` | `cubic-bezier(.2,0,0,1)` | Всё по умолчанию |
| `--ws-ease-exit` | `cubic-bezier(.4,0,1,1)` | Скрытие |
| Magnification | spring (stiffness 420, damping 32), радиус влияния ≈ 2.5 иконки, cos-кривая | Dock |

При `prefers-reduced-motion` выезды заменяются на fade, magnification отключается.

## Компоненты

| Компонент | Варианты / состояния | Примечание |
|---|---|---|
| `GlassSurface` | `level: bar \| panel \| menu` | Единственный способ сделать стекло; знает о фолбэке без blur |
| `IconButton` | default, hover, pressed, focus, disabled | 32px, иконка 18px |
| `CategoryPill` | default, hover, selected, drag-over | Иконка + текст, selected — `--ws-accent-fill` |
| `Tile` | default, hover, pressed, selected, drag, missing (объект не найден) | Иконка 32px, название, мета |
| `AddTile` | — | Пунктир, «＋ Добавить» |
| `SearchField` | default, focus, with-value | Иконка поиска, Esc очищает |
| `ContextMenu` | item, separator, danger, submenu, disabled | Клавиатура: стрелки, Enter, Esc |
| `Flyout` | `anchor: launcher \| dock` (виджеты / список окон) | Хвостика нет, отступ 8px от якоря |
| `DockItem` | idle, hover (magnified), running, active, attention, dragging | Индикатор 4×4px, active — 14×4px |
| `DockSeparator` | — | 1px `--ws-stroke-strong` |
| `Slider` | default, hover, dragging, disabled; опционально с уровнем пика | Для громкости: колесо мыши ±2% |
| `Toggle` | off, on, disabled | |
| `Select` | — | Нативно-подобный список устройств |
| `ListRow` | с иконкой, с ползунком (аудио по приложениям) | |
| `Tooltip` | — | Задержка 500ms, имя приложения над иконкой дока |
| `WidgetSlot` | — | Хост для `compact`-вида виджета |

## Иконки

- UI-глифы: Fluent UI System Icons (MIT), 20px regular / filled для активного.
- Иконки приложений и файлов — реальные системные (извлекаем в 256px), без перерисовки.
- Иконки категорий: набор Fluent + цветные «папки» как на концепте (цвет — параметр категории).
