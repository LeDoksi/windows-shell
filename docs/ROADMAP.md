# План по этапам

Правило из исходного документа остаётся: после каждого этапа приложение запускается и работает. Каждый этап — эпик (issue) с подзадачами; ниже — черновик канбана.

Метки: `area:dock`, `area:launcher`, `area:widgets`, `area:audio`, `area:core`, `area:design`, `area:infra`, `type:spike`, `type:feature`, `type:chore`, `risk:high`.

## Этап 0 — Фундамент и спайк

Цель: пустое приложение собирается в CI под Windows, и мы знаем ответы на рискованные вопросы.

- [ ] Скелет: Tauri 2 + React + TS + Vite, pnpm, ESLint/Prettier, `cargo fmt/clippy` — `area:infra`
- [ ] CI: GitHub Actions на `windows-latest`, сборка установщика как артефакт — `area:infra`
- [ ] Браузерный режим `dev:web` с мок-бэкендом — `area:infra`
- [ ] Спайк: Acrylic-подложка + прозрачное окно иконок, magnification, скругления — `type:spike risk:high`
- [ ] Спайк: окно без активации (`NOACTIVATE`), topmost против Taskbar — `type:spike risk:high`
- [ ] Спайк: autohide через опрос курсора, полноэкранные приложения, мультимонитор/DPI — `type:spike`
- [ ] Итог спайка: решение по стеклу записано в `ARCHITECTURE.md`

## Этап 1 — Дизайн-система и визуальный прототип

Цель: в браузерном режиме всё выглядит как концепт.

- [ ] Токены (цвет, радиусы, тени, отступы, типографика, motion) в CSS-переменных — `area:design`
- [ ] Базовые компоненты: GlassSurface, IconButton, Pill, Tile, SearchField, ContextMenu, Flyout, Slider, Toggle, Select, Tooltip — `area:design`
- [ ] Страница-витрина компонентов (`/playground`) — `area:design`
- [ ] Top Launcher: панель категорий (мок) — `area:launcher`
- [ ] Окно категории: сетка плиток, поиск, футер — `area:launcher`
- [ ] Dock: иконки, индикаторы, magnification (spring), разделитель, зона виджетов — `area:dock`
- [ ] Конфиг-стор (схема v1, дефолты = моки) — `area:core`
