# Без системного Taskbar: системный хвост дока и свой трей

Решение (2026-10-02): штатный Taskbar Windows убираем совсем. Всё системное, что от него нужно, живёт в **системном хвосте** — правой части дока после разделителя. Windhawk не нужен. Варианты расположения, из которых выбирали: артефакт «Где живёт системное».

## Состав хвоста

```text
 [приложения …]  │  ⌃   📶   🔊   🔋   12:23
                    │   │    │    │    2 окт
                    │   │    │    └ только на ноутбуке
                    │   │    └ наш аудио-виджет
                    │   └ сеть
                    └ фоновые приложения (трей)
```

| Элемент | По клику | Детали |
|---|---|---|
| ⌃ Фоновые приложения | Flyout с иконками трея сторонних программ | Красная точка на стрелке, если иконка мигает или сменилась на «внимание». ЛКМ/ПКМ/двойной клик пересылаются программе |
| 📶 Сеть | Flyout: текущая сеть, список Wi-Fi, переключатель Wi-Fi, «Параметры сети» | Иконка показывает Ethernet / уровень Wi-Fi / нет сети |
| 🔊 Звук | Наш аудио-виджет (см. [WIDGETS.md](WIDGETS.md)) | Колесо мыши ±2%, средний клик — mute. Системный flyout Windows не используем |
| 🔋 Батарея | Flyout: процент, время до разряда/заряда, режим питания | **Показывается только если в системе есть батарея** (`GetSystemPowerStatus`, `BatteryFlag != 128`). На ПК элемента нет |
| Часы | Flyout: календарь месяца, дата | Время и короткая дата в две строки |

Порядок фиксированный, в настройках можно скрыть любой элемент, кроме часов.

## Как убираем Taskbar

- Включаем автоскрытие (`SHAppBarMessage(ABM_SETSTATE, ABS_AUTOHIDE)`), чтобы рабочая область стала на весь экран, и прячем окна `Shell_TrayWnd` и `Shell_SecondaryTrayWnd` (вторые мониторы). Так делает открытый Cairo Desktop.
- Explorer иногда показывает Taskbar снова: после перезапуска проводника (сообщение `TaskbarCreated`), смены мониторов, некоторых хоткеев. Слушаем эти события и прячем заново.
- **Сторож.** При выходе возвращаем исходное состояние (видимость и прежнюю настройку автоскрытия). На случай падения — отдельный крошечный процесс-сторож: если основной процесс умер, он возвращает Taskbar. Плюс пункт в меню трея «Вернуть Taskbar» и аварийный хоткей.
- Пуск по клавише Win, уведомления (Win+N) и быстрые настройки Windows (Win+A) продолжают работать.

## Свой трей (самое рискованное)

Программы добавляют иконки в трей через `Shell_NotifyIcon`, который отправляет `WM_COPYDATA` окну с классом `Shell_TrayWnd`. Чтобы получать их, мы:

1. Создаём своё окно класса `Shell_TrayWnd` поверх штатного, чтобы сообщения приходили нам, и пересылаем их штатному, чтобы Explorer не ломался. Это подход библиотеки ManagedShell (на ней работает Cairo Desktop), портируем на Rust.
2. Рассылаем `TaskbarCreated`, чтобы уже запущенные программы перерегистрировали свои иконки.
3. Держим модель: `hWnd + uID → иконка, подсказка, uCallbackMessage, версия`. Отдаём в UI диффы.
4. Клики пересылаем программе по её `uCallbackMessage` с учётом `NOTIFYICON_VERSION_4` и координатами иконки; перед этим даём программе право стать активной (`AllowSetForegroundWindow`), иначе её контекстное меню не закроется по клику мимо.
5. Скрытые/«всегда показывать» иконки — пока все в одном списке, порядок перетаскиванием (после MVP).

Риски: 
- Поведение между сборками Windows 11 (24H2/25H2) нужно проверять на реальной машине. Поэтому это первый пункт спайка этапа 0.
- Если перехват не удался, фолбэк: выезд штатного Taskbar по клику на ⌃ (временно снимаем скрытие).

## Сеть

- Состояние: `INetworkListManager` (есть ли интернет, тип подключения) + WLAN API (`WlanEnumInterfaces`, `WlanGetAvailableNetworkList`, `WlanQueryInterface` для уровня сигнала).
- Подключение к известной сети — `WlanConnect` с сохранённым профилем. Ввод пароля новой сети в MVP не делаем: кнопка открывает системные «Параметры → Wi-Fi».

## Часы и батарея

- Часы: обновление раз в минуту по границе минуты, формат из региональных настроек Windows.
- Батарея: `GetSystemPowerStatus` + уведомление `RegisterPowerSettingNotification(GUID_BATTERY_PERCENTAGE_REMAINING)`; режим питания через `PowerGetEffectiveOverlayScheme`/`PowerSetActiveOverlayScheme`.

## Что теряем без Taskbar

- Кнопки задач Windows (их заменяет наш Dock).
- Значок языка ввода. Переключение по Win+Space работает, индикатор можно добавить в хвост позже.
- Кнопку «Показать рабочий стол» в углу. Win+D работает.
