# Сеть — фактическая основа для будущего обсуждения

2026-11-02. Обсуждение адаптации; полный дизайн ещё не утверждён.
Прочитаны текущие `native/Shell/Tail/NetworkFlyout.cs` и `Wlan.cs`;
сети не сканировались, подключения и настройки не менялись.

## Решения пользователя

- Подключение к новой сети, включая ввод пароля, проходит целиком внутри острова.
- Знакомые сети видны сразу.
- Незнакомые сети находятся в раскрывающейся секции/списке. Конкретный вид
  раскрытия ещё не утверждён; отдельное внешнее окно не требуется.
- Оформление и переходы — часть единого дизайна острова с постоянной лентой.
- Позднее из топ-10 новых возможностей пользователь выбрал управление
  Bluetooth-подключениями как расширение сети. Затем подтвердил добавление
  и сопряжение новых устройств прямо внутри острова; заряд остаётся
  в виджете заряда.

Предлагаемая автором трактовка списка: из доступных поблизости сетей сохранённые
профили показывать в основной части, остальные — в секции «Другие сети».
Текущее подключение и его статус видны сразу. Выбор новой сети переводит её
в состояние ввода пароля и подключения внутри общего тела; открытая сеть
не запрашивает несуществующий пароль. Конкретное размещение формы ещё не выбрано.
Показ сохранённых, но отсутствующих поблизости профилей отдельно не обсуждался.

## Что реализовано сейчас

- Текущее подключение и статус из NetworkService: в том числе Ethernet/Wi-Fi,
  наличие сети и интернета.
- При доступном Wi-Fi-адаптере — переключатель радио и список доступных сетей.
- Строки содержат SSID, уровень сигнала, защиту и состояние подключения.
- Подключение к известному профилю из виджета; для текущей сети есть отключение.
- Для новой сети, неудачного подключения и недоступного управления радио
  предусмотрен переход в соответствующие настройки Windows.
- Собственного ввода пароля новой сети нет; показаны до 12 сетей с прокруткой.
- Есть состояния поиска, отсутствия сетей и ограниченного разрешения на
  местоположение; ссылки открывают системные настройки, не меняя разрешение сами.
- Во время подключения отображается индикатор, состояние опрашивается до
  результата или истечения ожидания. При закрытии панели опрос прекращается.

## Что нужно будет обсудить

- Какие сетевые действия пользователь реально использует и чего не хватает.
- Вид внутри острова для Ethernet, Wi-Fi, отсутствия адаптера и интернета.
- Как выглядит внутренний сценарий новой сети: форма, состояние подключения,
  неверный пароль, недоступность и повторная попытка без потери контекста.
- Нужны ли скрытые сети и корпоративные способы подключения: объём пока не выбран.
- Внутренние состояния Bluetooth, включая согласованное сопряжение новых
  устройств, и доступные API. Требуемый сценарий выбран, реализация не готова.
  VPN по-прежнему не включён в согласованный объём.
- Изменения логики/статусов, события и их настройки, keyboard/focus и motion.

Будущий перенос — с дублированием доступа в доке и острове до пользовательской
проверки. Существующие источники и действия сохраняются, новый UI должен стать
частью единого тела острова. Новый внутренний сценарий потребует расширения
нынешнего пути подключения: текущий Wlan.Connect работает только с уже
существующим профилем. Способ создания профиля и обработки разных типов
аутентификации нужно исследовать в будущей разрешённой реализации.
Пароли не должны попадать в журналы и диагностические артефакты.
Это не выполненная реализация и не проверенное подключение.
