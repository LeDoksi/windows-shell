# Уведомления — подготовка для Dynamic Island

2026-11-02. Обсуждение требований; продуктовый код не меняется.

## Согласовано пользователем

- Нужен собственный центр со списком уведомлений внутри острова.
- Обычно хватает всплывающих сообщений, но нужен и накопленный список.
- Поступление нового уведомления — отдельный тип события острова.
- Системные всплывашки заменяются событиями острова: пользователь выбрал замену,
  а не параллельный показ. Одно сообщение не должно всплывать дважды.
- Действуют общие правила: независимое отключение события, отсутствие
  автоматического переключения открытого виджета, подавление события поверх
  полноэкранного приложения. Новое исключение для fullscreen не согласовано.
- Общие дизайн, анимации и motion острова распространяются на центр.
- В «Не беспокоить» уведомления накапливаются молча: без раскрытия острова,
  звука и привлечения внимания. После выключения режима список сохраняется,
  пропущенные всплывашки не показываются очередью.
- Пачка уведомлений одного приложения объединяется в одно всплытие:
  последнее сообщение и счётчик остальных. Все сообщения остаются в центре.
- История автоматически удаляется через три дня. Правило автора для реализации:
  три суток с получения; это не удаление сообщений в приложении-источнике.
- Отдельные выключатели всплытий по приложениям пользователь отклонил.
  Общая настройка события и «Не беспокоить» сохраняются.

## Что есть в исходниках

Источник: `native/Shell/Tail/InputLanguage.cs`, класс `Notifications`, и
`native/Shell/Dock/Dock.Tail.cs`, ветка `notifications`.

Текущий сервис отслеживает идентификаторы уведомлений, флаг непрочитанности
и режим «Не беспокоить». Доступ к listener зависит от разрешения Windows;
есть запасной сигнал от сообщений трея. Клик помечает состояние прочитанным
и открывает системный центр Windows через Win+N. Готового списка с содержимым,
действиями и собственной историей это не предоставляет.

## Решения, которые ещё предстоят

- Состав списка, группировка внутри центра, прочитанность и очистка.
  Объединение пачки во всплытии уже согласовано.
- Доступные действия при открытии уведомления.
- Источники, полнота данных, синхронизация с Windows и приватность.
  Срок хранения собственной истории — три дня; отдельные выключатели
  всплытий приложений не добавлять.

Возможность заменить системные всплывашки, получать содержимое и сохранять
действия универсально ещё не исследована и не подтверждена. При подготовке
технического плана проверить поддерживаемые API и ограничения; не обещать
полное воспроизведение возможностей Windows на основании текущего флага Unread.
Техническое исследование должно проверить замену без молчаливой потери уведомлений
и дублей. На этапе подготовки системные настройки уведомлений не меняются.
