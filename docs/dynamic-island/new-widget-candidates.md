# Новые возможности острова — топ-10 для обсуждения

2026-11-02. Исходная подборка автора и последующий выбор пользователя.
Выбраны направления для подготовки; полного согласования дизайна и разрешения
на реализацию пока нет. Часть возможностей расширяет существующие виджеты
и не требует отдельного значка.

## Выбор пользователя

В текущую подготовку входят **3, 5, 7, 8**: OCR/текст с экрана, Bluetooth,
полка файлов и обработка текста буфера. Пункты 1, 2, 4, 6, 9, 10 в текущий
набор не включены. Новые события, исключения для fullscreen и закрепление
выбранных инструментов автоматически этим не добавляются.

## Исходный топ-10

| № | Кандидат и полезный сценарий | Место в острове | Источник и вопросы подготовки |
| --- | --- | --- | --- |
| 1 | Таймер и секундомер: быстро отсчитать время или поставить короткое напоминание | Компактный виджет времени | Локальное состояние; определить сохранение, окончание и правила события. Нового исключения для fullscreen пока нет |
| 2 | Быстрые заметки: сохранить мысль, черновик сообщения или фрагмент текста | Короткая запись и список заметок | Локальное хранение; определить срок, удаление и сохранение черновика |
| 3 | Текст с экрана: выделить область картинки, видео или ошибки и скопировать распознанный текст | Расширение снимков | OCR, языки, качество распознавания; захват области остаётся отдельным режимом выбора, результат внутри острова |
| 4 | Калькулятор и конвертер: выражения, проценты, единицы измерения | Один ввод и копируемый результат | Локальные вычисления; определить единицы и формат. Курсы валют в этот кандидат не включены |
| 5 | Bluetooth-подключения: увидеть и подключить знакомые наушники или геймпад | Расширение сети; заряд остаётся в виджете заряда | Проверить API подключения и сопряжения, доступные состояния. Нынешние данные о заряде не равны готовому управлению Bluetooth |
| 6 | Быстрый перевод: текст из буфера → перевод → копирование | Компактный текстовый инструмент | Выбрать локальную модель или сервис, языки, стоимость и правила передачи текста; текущие данные никуда не отправляются |
| 7 | Полка файлов: временно собрать файлы из разных папок для дальнейшего перетаскивания | Небольшая подборка файлов | Определить ссылки или копии, drag-and-drop и недоступные пути. Удаление с полки не должно удалять оригиналы; не дублировать историю буфера |
| 8 | Обработка текста буфера: сменить регистр, убрать лишние строки, исправить неверную раскладку | Расширение буфера обмена | Локальные явные преобразования с сохранением исходника. Вставка без форматирования уже есть и не считается новой возможностью |
| 9 | Раскладки окон: сохранить расположение окон на двух экранах для работы или игры | Выбор сохранённой раскладки | Проверить разные DPI, изменившиеся экраны и отсутствующие окна. Отдельная существенная задача по управлению окнами |
| 10 | «Не засыпать»: временно запретить автоматический сон на выбранное время | Компактный системный переключатель | Штатный запрос активности; определить срок и явное завершение. Не менять настройки питания молча |

Приоритеты реализации выбранных четырёх направлений ещё не определены.
Полка файлов требует проверки drag-and-drop и правил хранения.

## Ответы пользователя на блок из пяти вопросов

1. OCR — оба входа: выделение области экрана и уже сохранённые снимки.
2. Результат OCR сначала проверяется и исправляется внутри острова, затем
   копируется после подтверждения. Сразу буфер не заменять.
3. Bluetooth включает добавление и сопряжение новых устройств внутри острова.
4. Полка сохраняется до ручной очистки, в том числе между запусками оболочки.
5. Преобразования работают только с содержимым буфера. Обработка выделенного
   текста в другом приложении по горячей клавише не включена.

Дополнительно согласовано: преобразование текста сначала показывает
«было → стало» и заменяет содержимое буфера только после подтверждения.

Для полки пользователь выбрал ссылки на исходные файлы без самостоятельных копий.
Удаление с полки не удаляет оригинал. Состояние недоступного исходного файла
ещё проектируется. Для OCR и Bluetooth требуются проверка API,
ошибок и сценариев отмены. Выбор поведения не подтверждает техническую готовность.
Оригинальные файлы и текст другого приложения не менять без явного действия
пользователя. Текстовые операции остаются частью общего интерфейса буфера,
для которого согласован вызов рядом с местом ввода и новый дизайн и motion.

## Примеры существующих сценариев

- [Microsoft PowerToys Text Extractor](https://learn.microsoft.com/en-us/windows/powertoys/text-extractor):
  распознавание текста в выбранной области экрана; качество и языки требуют учёта.
- [Microsoft PowerToys Advanced Paste](https://learn.microsoft.com/en-us/windows/powertoys/advanced-paste):
  преобразования содержимого буфера. Это ориентир для явных операций над текстом,
  не подтверждение наличия всех предложенных операций в PowerToys.
- [Microsoft PowerToys Workspaces](https://learn.microsoft.com/en-us/windows/powertoys/workspaces):
  сохранённые расположения приложений как пример сценария работы с экранами.
- [Microsoft PowerToys Awake](https://learn.microsoft.com/en-us/windows/powertoys/awake):
  временное предотвращение сна штатным запросом без изменения плана питания.

Это примеры пользы, а не выбор зависимостей или предложение установки PowerToys.
Совместимость конкретных функций с нынешним WinUI-приложением не проверена.
Закрепление по принятому правилу остаётся только у монитора ПК; новые кандидаты
не получают его автоматически. События каждого выбранного кандидата обсуждаются отдельно.
