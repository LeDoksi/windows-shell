## Реальные источники событий и возможная роль острова

В правой колонке — варианты поведения острова; согласование указано явно.
Ни один из этих вариантов ещё не реализован в острове.
Наличие сервиса в коде не подтверждает, что он включён в пользовательском конфиге
или получает данные от конкретного устройства сейчас.

| Событие | Что уже есть в коде | Предложение для обсуждения |
| --- | --- | --- |
| Низкий заряд периферии | `Charge/ChargeService.cs`: пороговые предупреждения, защита от повторов; Windows toast и собственный баннер в игре | Сценарий согласован; длительность, действия и замена существующих предупреждений требуют решения |
| Снимок сделан, запись сохранена, GIF готов | `Shots/ShotsService.cs`: готовый файл и миниатюра `ShowThumb`; отдельные ошибки сохранения | Результат снимка/записи согласован; GIF и детали взаимодействия отдельно не обсуждались |
| Запись экрана идёт / на паузе | `ShotsService.Recording`, `RecordingTime`, `RecordingPaused`, `Tick`; есть отдельная рамка управления | Компактный индикатор текущей записи согласован; детали паузы, остановки и совместимости с другими виджетами ещё не выбраны |
| Переключилась раскладка | `Tail/InputLanguage.cs`: текущая раскладка, событие `Changed`, переключение через существующий сервис | Автопоказ смены раскладки согласован; точный вид, длительность и поведение при открытом виджете ещё не выбраны |
| Сменился аудиовыход, громкость или mute | `Audio/AudioService.cs`: `Changed`, endpoint callbacks и текущее состояние | Автопоказ смены аудиовыхода отклонён: устройство меняется через виджет, результат уже виден там; громкость и mute отдельно не обсуждались |
| Сменился трек / воспроизведение | `Media/MediaService.cs`: `Changed`, название, исполнитель, обложка, play/pause | Необязательная короткая карточка; частые смены трека могут отвлекать |
| Интернет пропал / восстановился | `Tail/NetworkService.cs`: `NetState.Internet`, `Changed` | Сообщение после устойчивого изменения; правила ожидания ещё предстоит определить |
| Непрочитанные уведомления | `Tail/InputLanguage.cs`: флаг `Unread`, DND, listener при разрешении Windows, запасной сигнал от трея | Не считать готовым агрегатором текстов всех уведомлений; сервис сейчас отслеживает идентификаторы и флаг |

Не включать таймеры, входящие звонки или произвольные загрузки приложений
в перечень уже подключённых к острову событий. Их источники и интеграции
этой проверкой не подтверждены.

## Стартовые сценарии и оставшиеся предложения

- Пользователь согласовал низкий заряд устройств, результат снимка/записи
  и компактный индикатор текущей записи экрана, затем добавил переключение
  раскладки ввода. Смену аудиовыхода исключил.
- В системной части дока остаются трей и часы; язык ввода и прочие элементы
  системной части переходят в остров. Приложения и Пуск этим решением не удаляются.
- Уточнение пользователя 2026-11-02: остров на каждом мониторе, автоматические
  сообщения — на мониторе с активным окном. Одновременное раскрытие виджетов
  на нескольких экранах пока не согласовано. Проверка версии выше относится к 2026-11-01.
- Пользователь согласовал запрет обычных автоматических появлений поверх
  полноэкранного приложения. Позднее уточнил два исключения: низкий заряд
  периферии и постоянный индикатор текущей записи с прошедшим временем.
  Первоначальное ограничение только предупреждением о заряде заменено.
- Ручной вызов в полноэкранном режиме согласован 2026-11-02: наведение отключено,
  вызов горячей клавишей доступен. Сочетание ещё не выбрано; политика подавленных
  сообщений после выхода из полноэкранного режима отдельно не согласована.
- Ниже остаются предложения ассистента, ещё не согласованные в деталях.
- Самостоятельное появление — только компактное; раскрытие большого виджета по клику.
- Не дублировать существующие toast, миниатюру и баннер одним и тем же сообщением.
- Уведомления о каждом копировании, изменении корзины или обновлении канбана
  по умолчанию не предлагать: наличие изменения данных не означает необходимость отвлекать.
- Полноэкранный режим для автоматических событий и ручного вызова определён выше;
  остаются выбор сочетания клавиш, поведение уже открытого виджета при входе
  в полноэкранный режим и событий после выхода из него.
